# Have You Tried Turning It Off?

`Have you tried turning it off and on again? The router — your toaster doesn't have WiFi.`

Run it with `node main.ts` — the program prints the single entry line to stdout.

The joke is the classic "turn it off and on again" support line redirected at a toaster — routers need reboots, kitchen appliances don't (yet). Your microwave is safe. For now.
